# KisanLink — Real-time Data Requirements

## Remove demo/mock data
The mobile app must not present hard-coded market prices, buyer offers, balances, listings, transactions, or notifications as real data. Seed/demo records must be explicitly labelled `Demo` if retained for evaluator mode.

## Required production integrations
1. **Market prices:** official/authorized mandi/e-NAM/APMC source or licensed feed. Store source, mandi, crop/variety, min/modal/max, arrival volume, unit, timestamp, and freshness.
2. **Identity:** real OTP provider for mobile authentication; optional AgriStack/Meri Pehchaan integration only after authorization/credentials are available.
3. **Users:** PostgreSQL/Neon users, roles, profile, KYC status and consent.
4. **Produce listings:** PostgreSQL-backed CRUD with farmer ownership, crop, quantity, quality, photos, location, asking price and lifecycle status.
5. **Buyer marketplace:** verified buyer records, bids/offers, contracts, timestamps and server-side authorization.
6. **Transactions/escrow:** transaction state machine, order/lot references, payment provider/bank integration and webhook verification. Never show a balance unless it comes from a persisted transaction/account source.
7. **Notifications:** persisted notifications generated by backend events; push notifications require FCM/APNs credentials.
8. **Logistics:** authorized transporter/GPS API or a real logistics backend. Pickup ETA and route data must carry source/time.
9. **Computer vision grading:** real inference endpoint/model with model version, confidence and image ID. Never display fabricated confidence.
10. **Weather/demand insights:** authenticated weather/market-demand APIs where used; every insight should expose source and timestamp.
11. **Storage/FPO:** real FPO, warehouse and capacity records, with booking status from backend.

## Mobile-app behavior
- First launch always opens authentication/onboarding.
- Protected screens redirect to `/login` when no valid JWT exists.
- Store JWT securely in the native shell when available; use localStorage only as web fallback.
- Add loading, offline, empty, stale-data and API-error states.
- Display `Updated <time>` and data-source labels for time-sensitive insights.
- Use Capacitor-safe touch targets, safe-area insets, bottom navigation and no desktop-width layout.
- Logo asset is `assets/kisanlink-logo.png`; use it in splash/login/header/favicon where supported.

## Environment variables
Frontend: `VITE_API_BASE_URL`.
Backend: `DATABASE_URL`, `JWT_SECRET`, OTP provider credentials, market-data credentials, payment credentials, storage/logistics credentials and push-notification credentials as applicable. Never commit secrets.
